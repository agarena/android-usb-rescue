# 各品牌差异备注

按品牌列出影响本救援流程的差异点。没有列到的品牌先按通用流程走，卡住再查这里。

## 小米 / 红米（MIUI / 澎湃 OS）

- **双开关**：「USB调试」只给基础 shell；`input keyevent` 等模拟输入必须再开「USB调试（安全设置）」——需要插 SIM 卡并登录小米账号，缺一会置灰；
- 「仅充电」模式下 adb 依然可用；「传输文件」模式额外开放 MTP 存储；
- 进 fastboot：关机状态按住「音量下」插线即可（不需要电源键）；开机状态下「音量下+插线」会直接重启进 fastboot——电源键坏了反而好进；
- 相册：`DCIM/Camera`；长截屏等在 `DCIM/Creative`；
- 授权弹窗偶尔不在锁屏出现：解锁后拔插数据线必现。

## 华为 / 荣耀（EMUI / Magic OS）

- 有独立开关「“仅充电”模式下允许 ADB 调试」——如果 adb 死活不上线先查这个；
- 「仅充电」默认隐藏 adb 与 MTP，下拉通知栏把 USB 用途改为「传输文件」；
- 双击亮屏默认关闭：设置 → 辅助功能 → 快捷启动及手势 → 双击亮屏；
- 荣耀独立后（Magic OS）行为与华为基本一致。

## OPPO / 一加 / 真我（ColorOS）

- 开「USB调试」时有倒计时确认窗，按住 till 结束即可；
- 部分版本要求登录账号才能长期开启 USB 调试，重开机后可能要求重新确认；
- 一加/真我的 fastboot 通用 ID 多为 `18D1:D00D`。

## vivo / iQOO（OriginOS）

- 开发者选项入口隐藏较深（设置→系统管理→关于手机→版本信息连点「软件版本号」）；
- 开启 USB 调试需输验证码/答题，个别版本要求登录 vivo 账号；
- 「USB调试（安全设置）」同样存在，模拟输入需开启。

## 三星（One UI）

- **没有标准 fastboot**：三星的引导模式叫 Download Mode（Odin 协议），`fastboot devices` 永远为空，不要按本文 fastboot 流程套；
- Download Mode 进法：关机按住「音量下+音量上」插线；**退出**：长按「音量上+音量下」约 7 秒或等超时自动重启（不需要电源键）；
- 电脑端装 Smart Switch 自带驱动；
- 双击亮屏：设置 → 高级功能 → 动作与手势；AOD（息屏提醒）可直接在锁屏滑动手势。

## Google Pixel（原生）

- Google 官方 USB 驱动直接覆盖，无第 3 步 GUID 修正问题；
- 进 fastboot：关机按住「电源键+音量下」（电源键坏时：插线开机瞬间按音量下，或已开机时 `adb reboot bootloader`）；
- 双击亮屏不支持（原生无此功能），依赖抬手亮屏/插线亮屏。

## 通用提醒

- 「双击亮屏」「抬手亮屏」开关位置各品牌不同——直接在设置搜索框搜"双击"最快；
- 电源键彻底坏且未授权 adb 的机器，日常救急三板斧：双击屏幕、拔插数据线、背面/屏下指纹；
- `adb reboot` 可以替代电源键实现"重启手机"（长按电源键重启的替代）。
